### 🎧 About

A **frontend clone of Spotify's web player**, rebuilt from scratch with pure HTML, CSS, and JavaScript — sidebar navigation, a full playlist library, an artist page, and a functioning-look player bar with shuffle/play/next/repeat controls. Populated with real playlists across Punjabi, Bollywood, and Hindi music (Sidhu Moose Wala, Diljit, AR Rahman, Arijit Singh, and more) rather than generic placeholder content.

### ✨ Features

- 🎵 Sidebar library with 18+ playlists and artist entries
- 👤 Artist page layout (Arijit Singh example, with monthly-listener style stats)
- 🎛️ Player bar UI — shuffle, previous, play, next, repeat, volume, fullscreen
- ❤️ Liked Songs, Recents, and "Made For You" sections
- 🎙️ Podcast/episode row, matching Spotify's real layout patterns
- 📱 Structured, Spotify-accurate visual hierarchy
